```

  ├─ Hero：定位「AI 原生私有知识库」（标签：上手 AI · 图谱 · Agent 闭环 · 私有 · 无账户）

  │    4. 本地私有 / 零依赖
  │    5. 无账户协作
  └─ CTA：部署 + Agent Skills
```
