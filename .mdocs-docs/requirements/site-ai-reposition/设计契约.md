# site-ai-reposition — 设计契约

> **状态**：已同意（2026-07-28）  
> 拍板：保留主 slogan；CTA 主按钮不变 + 次按钮链 Agent 文档；新建 `agent-dev-loop.md`；特性区 AI 两条路径置顶。

## 方案摘要

把站点叙事改成 **「底座能力 + AI 两条路径」**：

```
人读首页
  ├─ Hero：定位「AI 原生私有知识库」（标签突出上手 Agent + Agent 开发闭环）
  ├─ Features（建议顺序）
  │    1. 上手助手（AI）——产品内答疑，读本站手册，不代写
  │    2. Agent 开发闭环——CLI Token + Skills（mdocs-cli / mdocs-dev / diagram）
  │    3. 本地私有 / 零依赖（原「本地数据」）
  │    4. 无账户协作
  │    5. 双模编辑 + 草稿（可合并为一节或各留一节，避免首页过长）
  └─ CTA：部署自己的库 + 链到 AI / CLI 文档

手册
  ├─ 文档首页分组增加「AI 与 Agent」
  ├─ 侧栏同构
  └─ 可选：新增 agent-dev-loop 总览页（待确认）
```

### 文案原则

| 要说清 | 不要说 |
|--------|--------|
| 问「怎么用 mdocs」有产品内 Agent | 自动写文章 / 润色正文 |
| Cursor 等可用 CLI+Skills 读写知识库、落 `.mdocs-docs` | 「一键接任意 Agent 平台」空话 |
| 手册真源 = 本站，会打包进上手 Skill | 运行时从公网拉手册（与 mdocs ADR 不符） |

### 建议 Hero 标签（草案，可改）

`上手 AI` · `Agent 开发闭环` · `私有部署` · `无账户协作` · `所见皆文件`

（旧「双模编辑 / 智能草稿」下沉到特性区，不再占 Hero 五格。）

### Slogan（默认方案，待确认）

- **默认**：保留「自由书写，一字不落」，副文案改为强调 AI（例如「产品内上手助手 · CLI 接入 Cursor / Claude · 手册即 Agent 知识」）。
- **备选**：主 slogan 改为 AI 向（需你点头）。

## 风险与回滚

| 风险 | 缓解 |
|------|------|
| 过度 AI 化，老用户找不到部署/协作信息 | 底座能力仍保留在特性区与文档 |
| 文案超前产品 | 严格对照 onboarding-ai 非目标；PR 自检清单 |
| FeatureSection 与 WhyMdocsPage 双份数据漂移 | 优先抽共享常量 `src/constants/selling-points.ts`（若改动面可控） |

回滚：还原上述文件即可；无后端依赖。
