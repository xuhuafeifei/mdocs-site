# 知识图谱

mdocs 的知识图谱用 AI 自动从你的文档中提取**概念**与**关系**，用力导向图可视化，帮你快速理解知识库的结构与关联。

---

## 核心概念

### 节点类型

| 类型 | 说明 |
|------|------|
| 📄 **文档节点** | 一篇 Markdown 文档对应一个节点 |
| 💡 **概念节点** | AI 从文档中提取的关键词、主题、概念 |

### 关系类型

| 关系 | 说明 |
|------|------|
| **contains**（包含） | 目录 / 文章 包含某个概念 |
| **related_to**（相关） | 两个概念之间存在关联 |
| **part_of**（部分） | 某个概念是另一个的组成部分 |
| **depends_on**（依赖） | 某个概念依赖于另一个（前置知识） |

### 三级构建

知识图谱是**分层自下而上**构建的：

1. **文章级**：从单篇文档提取概念
2. **目录级**：汇总子目录 / 文章的图谱，AI 归纳上层概念
3. **域级**：整个域的完整知识图谱

每一层都独立缓存，改了哪层重算哪层。

---

## 入口

### 目录级图谱

在文档树中，鼠标悬停在**目录**或**文章**上，会出现 🧠 图标，点击即可打开该目录/文章的图谱。

### 域级图谱

左侧边栏顶部，点击「**知识图谱**」按钮（🧠 图标），打开整个域的完整图谱。

---

## 图谱界面

### 交互操作

- **拖动**：按住空白处拖动画布
- **缩放**：鼠标滚轮缩放
- **悬停**：鼠标移到节点上，高亮相关节点与连线
- **点击节点**：右侧详情面板展示节点信息
- **工具栏**：
  - 🔄 重新生成 — 强制重算图谱
  - 📄 显示/隐藏文档节点 — 只看概念节点更清爽
  - 🔍 搜索节点 — 按名称定位
  - ➕/➖ 缩放
  - ⛶ 适应视图

### 详情面板

右侧面板显示当前选中节点的：
- 名称 / 类型
- 关联的节点列表（可点击跳转）
- 关系说明

## 生成与缓存

### 首次生成

第一次打开图谱时，点击「**生成图谱**」按钮，AI 会：
1. 逐篇提取文章概念
2. 自下而上归纳目录级概念
3. 生成概念之间的关系

时间取决于文档数量，几十篇文章大概几十秒。

### 缓存与更新

生成后图谱会缓存到磁盘上，之后打开秒开。

**什么时候会自动重算？**
- 正文内容变化超过 **15%**（行级变化率）
- 文章被删除、移动
- 目录结构变化

小改动（改几个字、调个格式）不会触发重算，省 token 也省时间。

### 强制重算

工具栏点「重新生成」按钮，随时可以手动强制重算。

## 使用场景

- **快速上手一个新域**：打开域级图谱，一眼看明白有哪些核心概念、它们之间什么关系
- **找相关文档**：点一个概念节点，看看哪些文档提到了它
- **发现知识缺口**：两个概念应该有关系但图上没有？可能文档里没写清楚
- **梳理知识结构**：从概念视角审视你的知识库，而不是单纯按文件夹分类

---

## 注意事项

- 图谱是 AI 生成的，**不保证 100% 准确**，作为参考即可
- 生成需要消耗 API 调用（token），大目录/域会比较贵
- 图谱数据存在隐藏文件中，不会出现在文档树里
- 删除文档会异步清理对应的图谱缓存，不用担心残留
