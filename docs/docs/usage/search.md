# 全文搜索

mdocs 内置基于 FTS5（SQLite 全文索引）的搜索，支持中文 jieba 分词。

## 搜索入口

- **侧栏**：目录区域的搜索图标
- **快捷键**：`⌘K`（macOS）/ `Ctrl+K`（Windows / Linux）

打开后是屏幕中部的悬浮搜索框，默认只搜**当前工作空间**。点击结果用文档 ID 打开文章并关闭浮层。

## 搜索能力

- **标题优先**：标题与正文分两路索引；标题命中权重更高，排序更靠前
- **全文检索**：正文同样可搜；两路结果按文档合并打分
- **中文分词**：写入与查询都走 jieba，提高中文召回
- **权限过滤**：自动过滤当前访客无权阅读的文档
- **结果信息**：展示标题、作者、最后修改时间、路径与正文片段

## 限制搜索范围

Web 端浮层固定为当前工作空间。CLI / Agent 可通过 `domainId` 限定范围；不传则可跨可读工作空间检索。

## 索引更新

- 文档创建或更新后自动标记 dirty，异步重建（正文 + 标题两路）
- 默认约每 60 秒扫描一次待索引文档
- 索引更新不影响文档正常访问
